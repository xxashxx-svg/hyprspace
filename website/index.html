Loops & automations

Agents that don't stop at one turn.

Give a loop a goal and a stop rule. It runs an agent headless, over and over — until your tests pass, until a task list is empty, or every night at 3am — then hands you the diff to review.

Run it your wayUntil done, on a schedule, every N minutes, or once. Keep context across passes or start each fresh.
It can't run foreverA hard max iterations cap is mandatory — plus optional stops on a passing check, a sentinel, a time budget, or no progress.
Isolated, then reviewedLoops run on a throwaway git worktree, never your working tree. Read the diff and merge when you're happy.
