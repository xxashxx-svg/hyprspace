Automations

Agents that don't stop at one turn.

Give an automation a goal and a stop rule. It runs an agent headless, over and over, until your tests pass, until a task list is empty, or on a real cron schedule. Then it notifies you with the diff to review.

Run it your wayUntil done, every N minutes, once, or on a full cron expression like */30 9-18 * * 1-5. Keep context across passes or start each fresh.
It can't run foreverA hard max iterations cap is mandatory, with optional stops on a passing check, a sentinel, a time or token budget, or no progress. Failed runs retry with backoff, then stop and alert you.
Isolated, then reviewedAutomations run on a throwaway git worktree, never your working tree. Every run is kept in history with what it changed, what it cost, and why it stopped.
